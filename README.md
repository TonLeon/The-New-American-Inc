# The New American, Inc.

Advertisement in the émigré newspaper *Novyi Amerikanets* (New York, 1980) as a guide to a new life:
a map of the addresses, figures, and the ads themselves.

This repository holds the built website only, served by GitHub Pages.
It is generated from the design canvas by `export/build_site.py` in the research project; edit there, not here.

Street data © OpenStreetMap contributors.
